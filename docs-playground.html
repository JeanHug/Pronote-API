Pronote API

Passerelle éphémère haute performance pour l'ENT 77 & Pronote.

Service en ligne

🔒 Respect strict du RGPD et architecture éphémère

Cette API fonctionne selon un modèle strictement sans état. Aucune session, aucun cookie, et aucun mot de passe n'est stocké en base de données ni conservé en mémoire vive. À chaque appel, un navigateur Chromium neuf est lancé, extrait vos données chiffrées de bout en bout, puis s'éteint immédiatement (browser.close()).

Les exemples de cette documentation utilisent exclusivement des données fictives et anonymisées.

1. Spécification de l'API

POST https://pronote-api.hugdu77777.workers.dev/api/scrape-pronote

Déclenche une extraction éphémère immédiate (notes, emploi du temps, devoirs, ressources).

Corps de la requête (JSON) : 
{
  "username": "nom.prenom@ecole.fr",
  "password": "VotreMotDePasseENT",
  "pronoteUrl": "https://0771068t.index-education.net/pronote/eleve.html",
  "entUrl": "https://ent.seine-et-marne.fr/"
}
Exemple de Réponse 200 (Données anonymisées RGPD) : 
{
  "success": true,
  "executionTimeMs": 14200,
  "data": {
    "eleve": {
      "nom": "DUPONT Alex",
      "classe": "3EME 2",
      "etablissement": "COLLEGE EXEMPLE"
    },
    "notes": {
      "moyenneGenerale": 15.4,
      "toutesLesNotes": [
        { "matiere": "MATHEMATIQUES", "valeur": 17.5, "sur": 20, "date": "08/09" }
      ]
    },
    "emploiDuTemps": {
      "semaines": [{ "numeroSemaine": 37, "cours": [ /* Liste des cours */ ] }]
    }
  }
}
GET https://pronote-api.hugdu77777.workers.dev/api/health

Retourne l'état de fonctionnement en temps réel et le battement de session.
